 Najdôležitejšie si zapamätaj takto:

  Čiže tok je:

  klikneš algoritmus
  → zmení sa route
  → History ju uloží
  → vrátiš sa na home
  → index načíta históriu
  → zobrazí karty

  Toto je už dobrý kus React Native/Expo logiky naraz, takže dáva zmysel si to rozobrať pomaly.

  1. Začni v src/navigation/screenOptions.ts

  Tam máš spoločné farby navigácie. Pridal by som tam zvlášť screenBackground, aby bolo jasné, čo je pozadie obrazovky.

  dark: {
    background: "#0B1828",       // header / tab bar
    screenBackground: "#07111F", // pozadie obrazoviek a animácie
    primaryText: "#F5F8FC",
    primary: "#77B7F2",
    muted: "#AAB6C7",
    border: "#31435A",
  }

  2. V getHeaderOptions() pridaj contentStyle

  Toto je najdôležitejšie. contentStyle nastavuje podklad navigátora pod obrazovkami.

  export function getHeaderOptions(themeMode: AppThemeMode) {
    const colors = navigationColors[themeMode];

    return {
      headerStyle: { backgroundColor: colors.background },

      // Toto je farba, ktorú uvidíš medzi slide animáciami.
      contentStyle: {
        backgroundColor: colors.screenBackground,
      },

      headerTintColor: colors.primaryText,
      headerTitleStyle: {
        color: colors.primaryText,
        fontWeight: "bold" as const,
      },
      headerTitleAlign: "center" as const,
    };
  }

  3. Skontroluj root stack

  V app/_layout.tsx už používaš:

  ...getHeaderOptions(themeMode),
  animation: "slide_from_right",

  Čiže keď pridáš contentStyle do getHeaderOptions, root stack to automaticky dostane.

  V app/(tabs)/algorithms/_layout.tsx tiež používaš:
